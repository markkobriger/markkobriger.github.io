# Mark Kobriger | Resume Website

Live site: https://markkobriger.github.io

A responsive resume website built with semantic HTML and custom CSS. Designed for clear scanning, strong readability, and print-friendly output.

## Features
- Responsive layout (desktop and mobile)
- Clear section flow: Summary → Skills/Highlights → Experience → Projects → Education
- Education displayed side-by-side with school badges and links
- Print-friendly styling for resume-style output
- Lightweight, no frameworks and no build steps

## Tech Stack
- HTML5
- CSS3
- Git + GitHub Pages

## Repository Structure
All files are located in the repository root:

- `index.html` — main resume page
- `styles.css` — site styling (responsive and print rules)
- `cover-letter.html` — cover letter page
- `favicon-16x16.png` — favicon
- `Green Phoenix.PNG` — header logo image
- `UWGB.png` — UW–Green Bay logo
- `MATC.png` — Madison College logo

> Note: GitHub Pages is case-sensitive. Ensure filenames match exactly (including capitalization and spaces).

## Run Locally
Option 1: Open `index.html` in your browser.

Option 2 (recommended): run a local server:
- VS Code: install **Live Server** → open `index.html` → **Go Live**
- Python:
  - `python3 -m http.server`
  - open `http://localhost:8000`

## Deployment
This site is hosted with GitHub Pages. Pushing changes to the repository updates the live site.
